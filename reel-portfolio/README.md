# Рилс-портфолио «Делаю сайты для бизнеса»

Вертикальный ролик для Instagram Reels: мои проекты на настоящих экранах + призыв написать
в Директ или Телеграм.

Готовый файл: [`render/portfolio-reel.mp4`](render/portfolio-reel.mp4)

| Параметр | Значение |
|---|---|
| Кадр | 1080×1920, 9:16, 30 к/с |
| Длительность | ≈ 36,8 с, 7 сцен |
| Видео | H.264 High, yuv420p, BT.709, faststart |
| Звук | AAC 48 кГц, −14 LUFS |
| Озвучка | ElevenLabs, голос Pavel (eleven_v4, дубль 1 из 2), тайминги — ElevenLabs Scribe |
| Музыка | оригинальный бит, синтезирован кодом (`scripts/make-audio.mjs`) |

## Что настоящее

- **Настоящие экраны:** FLOWERSGREEN и JAPONICA запущены локально из их репозиториев с
  демо-данными из `db:seed` (каталог, цены, фото — демо), сняты Playwright (412×915, 2,5×).
  WasteZero AI — снимки из репозитория Hackathon-project (демо-данные). Marvel — этот репозиторий.
- В HUD на этих сценах стоит «● Настоящие сайты · демо-данные».
- Карточки, кнопки «Директ»/«Телеграм» и значки нарисованы кодом.

## Озвучка

авторство — для рекламы услуг нужен платный тариф (Starter и выше).
