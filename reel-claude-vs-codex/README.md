## Факты и честность

Сверено с открытыми источниками (ноябрь 2026): документация Codex CLI (developers.openai.com/codex/cli)
и обзоры сравнений. Что важно знать:

- **Подтверждено:** Codex CLI — открытый код (Rust, Apache 2.0) и умеет облачные задачи; Claude Code —
  закрытый продукт Anthropic на моделях Claude; оба работают в терминале, IDE и облаке; оба стартуют
  с подписки за $20 в месяц (Claude Pro / ChatGPT Plus), максимальные тарифы — $200.
- **Спорное — подано как мнение:** «экономнее по токенам» (по ряду сторонних тестов) и «хвалят за
  качество кода» — источники расходятся, поэтому в ролике это «по тестам» и «хвалят», а столбики в
  сцене 04 подписаны как иллюстрация (без цифр).
- **Быстро меняется:** у Codex с весны 2026 есть плагины, субагенты и скиллы — поэтому минус
  сформулирован как «плагины пока молодые, экосистема меньше», а не «не умеет».
- Все интерфейсы и значки нарисованы кодом — это не логотипы Anthropic или OpenAI и не снимки их продуктов.

## Озвучка ElevenLabs

Был сгенерирован дубль голосом **Dmitry D** (ElevenLabs, eleven_v4, 55,6 с, flow
«Рилс: Клод Код vs Кодекс»), но сеть этой сессии не пускает на `elevenlabsusercontent.com`,
поэтому файл не скачался. Чтобы подставить его: скачать MP3 из ElevenLabs →
`public/reel/voiceover.mp3`, расшифровку Scribe → `src/vo-words.json`, затем пересобрать (ниже).

## Как пересобрать

```bash
npm install
venv/bin/python scripts/tts-local.py <папка модели Piper dmitri>   # или подставить ElevenLabs, см. выше
npm run timeline && npm run audio
REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome-headless-shell npm run render
npm run finalize        # → render/claude-code-vs-codex.mp4
```
