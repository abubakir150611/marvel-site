# MCU Universe

Интерактивный 3D-портал по Кинематографической вселенной Marvel, построенный на Next.js 15, React, TypeScript, Tailwind CSS, Framer Motion, GSAP и React Three Fiber.

## Возможности

- Полноэкранная 3D hero-сцена (звёзды, порталы, энергетическое ядро) с эффектом приближения камеры при скролле
- Интерактивный таймлайн MCU по фазам 1–6 с карточками-комиксами, переворачивающимися как страницы
- База данных из 23 героев и 13 злодеев с индивидуальными страницами и 3D-портретами
- 3D-витрина шести камней бесконечности с подсветкой и информацией по наведению
- Портал в мультивселенную (Earth-616, Earth-838, Spider-Verse, What If...?, TVA)
- Вращаемая 3D-карта вселенной Marvel (Земля, Асгард, Ваканда, Квантовый мир и др.)
- Анимированная статистика, masonry-галерея и кинематографичные карточки битв
- Кастомный курсор, синтезированные звуковые эффекты, плавный скролл (Lenis), переходы между страницами
- SEO: метаданные, sitemap.xml, robots.txt, Open Graph

## Технологии

Next.js 15 · React 19 · TypeScript · Tailwind CSS · Framer Motion · GSAP · Three.js / React Three Fiber · Lenis

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
npm run start
```

## Примечание

Все постеры, портреты и визуальные элементы — это процедурные градиенты и 3D-объекты, сгенерированные средствами CSS/Three.js, без использования лицензированных изображений Marvel. Проект является неофициальным фан-сайтом.
