# Рилс «Claude vs Claude Code»

Вертикальный ролик для Instagram Reels: чем Claude Code отличается от обычного Claude в чате.
Стиль — «видео интерфейсом» (по присланному референсу): светлый холст, белые окна, терракотовые
кнопки, курсор с кликами, полосы выполнения, зелёные галочки, плюс хлёсткие цветовые поля и
кинетическая типографика.

Готовый файл: [`render/claude-vs-claude-code.mp4`](render/claude-vs-claude-code.mp4)

## Что настоящее, а что иллюстрация

- **Настоящее:** экран сайта на телефоне (сцена 06) — снимок этого репозитория `marvel-site`
  (Playwright, 412×915, 2,5×); имена файлов и число файлов в `src/` (52) в сцене 04.
- **Иллюстрация:** все окна, терминал, чат, комментарии и Директ нарисованы кодом в
  «интерфейсном» стиле; это не снимки claude.ai, Claude Code или Instagram и без их логотипов.
  Строки диффа, ошибка сборки и агенты — пример, а не запись реальной сессии.
- В HUD нет пометки «настоящий интерфейс» — потому что интерфейс нарисован.

## Как пересобрать

```bash
npm install
# озвучка ElevenLabs (голос Pavel): сохранить как public/reel/voiceover.mp3,
# пословную расшифровку Scribe — как src/vo-words.json ({"words":[{text,start,end,type}]})
# (запасной вариант без интернета: venv/bin/python scripts/tts-local.py <папка модели Piper>)
npm run timeline        # монтажный лист из таймингов слов (выравнивается со сценарием)
npm run audio           # бит + эффекты + голос → public/reel/reel-audio.m4a
REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome-headless-shell npm run render
npm run finalize        # → render/claude-vs-claude-code.mp4
```

Текст озвучки — `scripts/script.mjs`; сцены — `src/scenes/`, элементы интерфейса —
`src/components/Ui.tsx`. Все движения привязаны к номерам слов озвучки, поэтому после
замены голоса достаточно `npm run timeline && npm run audio && npm run render && npm run finalize`.

## Публикация

**Подпись к рилсу (пример):**

> Claude и Claude Code — не одно и то же 🤯
> Чат отвечает. Claude Code сам правит файлы, запускает тесты, пушит на GitHub и выкладывает сайт.
> Напиши «КЛОД» в комментариях — пришлю инструкцию, как подключить 👇
>
> #claude #claudecode #нейросети #ии #программирование #вайбкодинг #ai

Советы для рекомендаций: обложка — первый кадр («Что такое Claude Code?»); музыку Instagram
не добавлять поверх (в ролике уже свой бит); опубликовать как Reel, «Показывать в ленте» включено.

**Автоответ «комментарий → Директ» (ManyChat, официальный партнёр Meta):**

1. Аккаунт Instagram должен быть профессиональным (Автор или Бизнес).
2. manychat.com → войти через Instagram → разрешить доступ к сообщениям
   (Instagram → Настройки → Сообщения и ответы на истории → Инструменты для сообщений → «Разрешить доступ к сообщениям» — включить).
3. Automation → New Automation → триггер **«User comments on your Post or Reel»** → выбрать этот рилс
   (или «любой пост») → ключевые слова: `клод`, `Клод`, `КЛОД`, `claude`.
4. Включить **«Reply to comment»** (публичный ответ, например «Отправил в Директ 📩»).
5. Действие **Send Message** — текст сообщения (например: «Привет! Держи инструкцию по Claude Code: <ссылка>»).
6. Set Live. Проверить со второго аккаунта.
